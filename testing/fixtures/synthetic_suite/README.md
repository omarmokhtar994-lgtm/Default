# Synthetic suite and published benchmarks

Test inputs, not baselines. Every workbook here was generated by
`tools/build_synthetic_suite.py` (SYNTH_*) or `tools/build_benchmark_suite.py`
(BENCH_*), using `fixtures/SYNTHETIC_FIXTURE_FLOOR_NOT_80.xlsx` only as a format
template. `cases.json` holds each case's expectation and certificate;
`benchmark_exact.json` holds the independent exact solutions the BENCH_*
expectations come from.

Run them through the production runner and score:

```
python3 tools/run_synthetic_suite.py --engine-dir engine \
    --suite-dir fixtures/synthetic_suite --out-root <output dir>
```

Results and root causes: `evidence/NIGHT_14_TEST_SUITES_AND_BENCHMARKS.md`.
